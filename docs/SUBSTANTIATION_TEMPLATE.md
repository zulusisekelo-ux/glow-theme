# Substantiation Evidence Template

Purpose
- Keep a single, dated file that proves the whitening gel is packed with every in‑store kit. This file is for ad platform reviewers or regulators.

What to collect (minimum)
1. Packing photo(s)
   - One clear photo of the final packed kit showing the gel physically inside the box or tray.
   - Include a photo of the packing line or the packing checklist being ticked if possible.
   - Filename suggestion: packed-kit-YYYYMMDD.jpg
2. Supplier packing spec or invoice excerpt
   - A PDF or screenshot from the supplier that shows the kit contents or packing list.
   - Filename suggestion: supplier-packing-spec.pdf
3. Fulfilment SOP / internal checklist
   - A signed one‑line confirmation from the person responsible for packing (name + date) confirming every kit is packed with gel.
   - Filename suggestion: fulfilment-sop.pdf or packing-sop.pdf
4. Single combined PDF (recommended)
   - Combine the photos and documents into one PDF named GLOW_gel_substantiation_YYYYMMDD.pdf for quick upload to ad reviewers.

Where to store
- Upload the combined PDF and supporting files to Shopify Files (Admin → Settings → Files). Keep copies in your project documentation folder (claude/ or docs/) but do NOT commit photos containing sensitive supplier data to the public repo.

How to present to ad platforms
- Provide the single combined PDF when requested. In the ad review notes, state: "Gel is included with every kit — see attached substantiation (photo + packing spec + fulfilment SOP)."

Checklist before ad spend
- [ ] Photo(s) uploaded to Shopify Files
- [ ] Combined PDF uploaded to Shopify Files
- [ ] Product description updated in Shopify admin: includes the confirmed line
- [ ] Packing SOP saved in project docs and linked from docs/ in the repo

Notes
- Do not include private supplier banking or sensitive PII in the uploaded substantiation file. Keep supplier invoices redacted except for the packing/spec lines that show contents.
