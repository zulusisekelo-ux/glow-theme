# GLOW Temu Sourcing — Drop-Ship Model

## STATUS: the LED Mouth Tray 2-Pack was NOT built. Read why before rebuilding it.

Verified 2026-08-15. The earlier version of this file specified a
`glow-led-mouth-tray-2-pack` SKU at R149 with a ~R35–R45 landed cost and 70%+ margin,
sourced from this URL:

    https://www.temu.com/teeth-whitening-5020181107677-s.html

**That URL is not a product page.** It does not resolve to a listing — Temu redirects it
to a generic "teeth whitening" search results page. The product ID does not exist. The
cost figure and the margin that followed from it were never checked against a real
listing; they came from a search-engine summary.

Three further searches were run to find the product some other way:

| Search | Result |
|---|---|
| `silicone teeth whitening mouth tray 2 pack` | complete kits only |
| `teeth whitening mouth tray mouthpiece` (top sales) | complete kits, plus thermoform denture-moulding sets (not LED trays) |
| `silicone mouth tray for teeth whitening led light replacement` (top sales) | complete kits only |

**Conclusion: Temu does not sell a standalone LED whitening tray.** Trays come bundled
inside devices. The SKU as specified is not sourceable, so no Shopify product was
created for it.

Building it anyway would have meant publishing a page marked "In Stock" with a customer-
facing 8–10 business day promise, against a supplier that does not exist. That is the
same category of problem as the gel-in-the-box claim — see `docs/BACKLOG.md`.

## Sourcing rule going forward

Do not write a cost, a margin or a lead time into this file from a search result.
Open the listing, read the price and the sold-count off the page, and record the URL you
actually opened. Every figure in the verified section above was read off the live page.
